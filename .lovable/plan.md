# Tap to Pay handoff pack as a downloadable zip

Package the existing Tap to Pay documentation and iPhone screens into one zip file you can hand to Cursor.

## What you get

A single download, `tap-to-pay-handoff.zip`, containing one folder:

```text
tap-to-pay-handoff/
  README.md                  (the handoff instructions, ownership per screen)
  screens/                   (27 iPhone screenshots, named to match the doc)
```

The README is the handoff document already written: every screen listed with whether it is ours to build, supplied by Apple, or supplied by Adyen, which route it maps to, the compliance rules on naming and assets, iPhone-only behaviour, and which screens map to Apple's review clips 1 to 6.

## Notes

- Screens are captured at iPhone size (390x844) from the working prototype.
- Nothing in the app changes; this is packaging only.
- The zip lands in your documents so you can download it straight from chat.
