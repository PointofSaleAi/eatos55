# Gift Card left-column refinement

## Goal
Make the left column read as one clear gift-card workflow rather than three separate options, and replace the unexplained balance dash with useful guidance.

## Changes
- Add a concise introductory block at the top of the left column: **“Enter gift card details”** with supporting copy explaining that the same form handles purchasing a card, adding funds, and checking its balance.
- Rework the activation note into a small, polished informational row instead of the bracketed sentence from the reference.
- Keep the Gift Card Number and Amount fields prominent beneath the introduction, with the shared number pad continuing to follow the active field.
- Redesign Available Balance as a deliberate status area:
  - Before enough card digits are entered: **“Enter card number”**.
  - Recognized card: show the formatted balance.
  - Unrecognized valid number: **“New card”**, with clear activation context.
- Preserve the existing two-column desktop/tablet layout and stacked phone layout, adapting spacing and type for each size.

## Scope
Presentation and status wording only. Existing gift-card loading, balance lookup, payment behavior, and shared number-pad logic remain unchanged.
